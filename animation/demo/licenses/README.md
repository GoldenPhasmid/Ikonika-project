# Portable demo notices

This distribution contains the Lufi demo built from the source in `animation/demo`,
Qt 6.11.1 runtime components, Microsoft Visual C++ runtime libraries, and Microsoft
DirectX / software OpenGL runtime components deployed by Qt's Windows deployment tool.
The DLLs remain separate and replaceable.

Qt copyright and third-party attribution details are supplied in the accompanying
Qt-generated SPDX inventories in `qt-notices.zip`. GPL-3.0 and LGPL-3.0 license texts are included.
Qt Lottie is offered under GPL-3.0 or a commercial Qt license. The demo source is
available beside this distribution in the same repository. These demo packaging
choices do not change the main app's licensing or integrate this renderer into it.

Qt source corresponding to this runtime is available from:
https://download.qt.io/archive/qt/6.11/6.11.1/single/
Qt module source repositories: https://code.qt.io/cgit/qt/

The Blender exporter dependency is distributed separately with its GPL-3.0-or-later
license and source inside `animation/tools/ikonika-lufi-export.zip`.
